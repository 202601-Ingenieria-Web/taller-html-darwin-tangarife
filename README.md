# Rick and Morty Explorer

## Descripción
Aplicación web que consume la API pública de Rick and Morty para buscar y mostrar personajes.

## Tecnologías usadas
- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API

## Funcionalidades
- Búsqueda de personajes por nombre y por estado.
- Listado dinámico con imagen, nombre, especie y estado.
- Manejo de errores cuando no existen resultados.
- Diseño responsivo.

## ▶️ Cómo ejecutar
1. Descargar o clonar el repositorio.
2. Abrir el archivo `index.html` en el navegador dando click derecho y seleccionando 'Open with Live Server' .
3. ¡Listo!
